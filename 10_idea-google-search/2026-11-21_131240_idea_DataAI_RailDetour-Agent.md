# RailDetour-Agent: 철도 운행 중단 시 개인 일정 기준 대체 경로를 알려 주는 LLM 에이전트

## 1. 제안 범위 및 카테고리
- **영역**: 데이터 및 인공지능 (Data & AI)
- **세부 카테고리**: LLM App (에이전트)
- **직전 실행과의 관계**: 신규

## 2. 해결 문제와 사용자 페르소나
- **문제 정의**: 21일 오전 5시37분, 경부선 소정리역에 진입하던 화물열차가 탈선했다. 천안~전의 구간 전력 공급이 끊겨 천안역~대전역 일반열차 운행이 중단됐고, ITX-마음·새마을호·무궁화호가 잇따라 지연됐다. 반면 고속전용선을 쓰는 KTX와 충북선은 정상 운행했다. 같은 구간에서 열차 종류마다 상황이 달라 승객이 공지를 직접 해석해야 했고, 언론은 "수험생 유의"를 안내했다. 국토부는 재난 위기경보 '주의'를 발령했다(서울경제TV 헤드라인).
- **타겟 사용자**: 시험·면접·항공편처럼 도착 마감 시각이 고정된 일정이 있는 철도 이용자, 그리고 그 보호자
- **페르소나**: 지방에서 서울로 시험을 보러 가는 수험생의 보호자. 새벽에 사고 뉴스를 접하고 "우리가 탈 무궁화호가 서는지, KTX로 바꿔야 하는지, 버스가 나은지"를 30분 안에 결정해야 한다.

## 3. 핵심 기능 및 차별점
| 기능 | 설명 | 기존 대안 대비 차별점 |
|---|---|---|
| 공지 구조화 | 운영사 공지와 뉴스 텍스트에서 중단 구간, 열차 종류, 예상 재개 시각을 LLM으로 추출 | 지도 앱은 운행 중단을 늦게 반영하거나 열차 종류별 차이를 보여 주지 않음 |
| 마감 시각 기반 재계획 | 사용자가 등록한 "몇 시까지 어디 도착"을 기준으로 대체 열차, 고속버스, 환승 조합 계산 | 최단 경로가 아니라 마감 준수 확률 기준 |
| 사전 알림 | 등록 일정 전날~당일 새벽에 해당 노선 이상을 감지하면 푸시 | 사용자가 뉴스를 먼저 찾지 않아도 됨 |
| 근거 표시 | 판단에 쓴 공지 원문과 시각을 함께 표시 | LLM 오답 위험을 사용자가 확인 가능 |

## 4. 실행 계획 (MVP → 확장)
- **MVP 범위 (0~3개월)**: 경부선·호남선 일반열차 대상. 공지·뉴스 수집, LLM 구조화, 일정 등록, 텔레그램·카카오 알림. 만들지 않을 것: 예매 대행, 자체 지도, 전국 대중교통 통합.
- **확장 1단계 (3~6개월)**: 고속버스·시외버스 시간표 결합, 시험 일정 사전 등록 캠페인(학원, 학교 연계)
- **확장 2단계 (6~12개월)**: 기업 출장·물류 담당자용 B2B 알림 API, 기상 특보와 결합한 사전 위험 예보
- **기술 스택**: Python 수집기, LLM API(구조화 추출), 공공 교통 데이터 API(제공 범위는 추정이며 확인 필요), PostgreSQL, 메신저 봇 API

## 5. 수익 모델
- 개인: 기본 알림은 무료, 다중 일정·가족 공유는 소액 구독(가설)
- B2B: 학원·기업 출장 관리 부서에 단체 알림 계정 판매
- 제휴: 대체 교통(버스, 렌터카) 예약 연결 수수료
- 첫 유료 고객 경로: 입시·자격시험 학원과의 단체 계약

## 6. Go-To-Market
- 시험 시즌 전에 수험생 커뮤니티와 학원에 "시험 당일 교통 알림" 등록을 홍보한다.
- 운행 중단 사고가 날 때마다 대체 경로 요약 카드를 SNS에 공개해 인지도를 쌓는다.
- 첫 100명은 학원 2~3곳과 파일럿으로 확보한다.

|---|---|---|

| LLM 오추출로 잘못된 경로 안내 | 신뢰 손상, 책임 문제 | 원문 근거 병기, 확신도 낮으면 "공식 안내 확인" 표시 |
| 지도·교통 대형 앱의 기능 추가 | 경쟁 열위 | 마감 시각 기반 일정 관리라는 좁은 용도에 집중 |

## 9. 실현 가능성 점수: **3 / 5**
- **기술 난이도**: 중간. LLM 추출과 경로 계산은 기존 API로 가능하다. 다만 실시간 데이터의 정확도가 핵심이다.
- **초기 비용**: 낮음~중간. 수집 서버와 LLM 호출 비용 정도다.
- **시장 진입**: 실시간 운행 데이터 접근 범위가 불확실하고, 대형 지도 앱과 경쟁한다.
- **수요 신호**: 사실상 1건(경향신문 탈선 기사). 서울경제TV 헤드라인의 위기경보 발령은 같은 사건이라 독립 근거가 아니다. 수요 근거가 1건이어서 3점이다.
