# SchoolScreen-Pact: 학교·학생·학부모가 함께 쓰는 디지털 사용 약속·웰빙 수업 플랫폼

## 1. 제안 범위 및 카테고리
- **영역**: 서비스 및 플랫폼 (IT Services)
- **세부 카테고리**: 에듀테크
- **직전 실행과의 관계**: 신규

## 2. 해결 문제와 사용자 페르소나
- **문제 정의**: Bloomberg 보도에 따르면 YouTube는 "중독적 설계"가 아이들에게 해를 끼쳤다는 수천 개 학교구의 청구를 해결하려고 30억 달러를 지급하는 합의를 원칙적으로 맺었다. 합의에는 청소년 보호 장치 도입도 포함된다. 학교구가 직접 소송에 나설 만큼 학교 현장의 부담이 크지만, 학생의 디지털 사용 지도는 교사 개인의 역량에 맡겨져 있고 가정과 학교의 규칙도 따로 논다.
- **타겟 사용자**: 초·중학교 담임교사와 상담교사, 학교 정보부장, 교육청 디지털 시민교육 담당자, 학부모
- **페르소나**: 중학교 2학년 담임교사. 학생들의 수면 부족과 수업 중 집중력 저하가 늘었지만, 가정마다 스마트폰 규칙이 달라 상담할 때 기준으로 삼을 자료가 없다.

## 3. 핵심 기능 및 차별점
| 기능 | 설명 | 기존 대안 대비 차별점 |
|---|---|---|
| 디지털 웰빙 커리큘럼 | 학년별 45분 수업안 20차시(알고리즘 추천 원리, 자동재생·무한 스크롤 같은 설계 이해, 자기조절 전략) | 일회성 특강 대신 학기 단위로 운영하는 수업안 |
| 가정-학교 사용 약속 | 학생이 직접 목표를 정하고 학부모·교사가 함께 서명하는 디지털 약속 템플릿, 월 1회 돌아보기 | 앱 차단 도구와 달리 감시가 아닌 합의와 자기조절 중심 |
| 익명 학교 단위 리포트 | 학생 익명 설문으로 수면·사용 시간·자기평가 추세를 학교 단위로 집계 | 개인 추적 없이 학교 정책 결정 근거 제공 |
| 보호 기능 안내 | 주요 플랫폼의 청소년 보호 설정 방법을 학부모용 가이드로 최신 유지 | 플랫폼별 보호 기능 변경을 한곳에서 확인 |

## 4. 실행 계획 (MVP → 확장)
- **MVP 범위 (0~3개월)**: 중학교용 수업안 10차시, 약속 템플릿, 익명 설문과 학급 단위 리포트(웹). 만들지 않을 것: 학생 기기 모니터링·차단 앱, 개인 식별 데이터 수집, 의료·치료 기능
- **확장 1단계 (3~6개월)**: 초등 고학년 과정, 학부모 모바일 웹, 교육청 단위 집계 리포트
- **확장 2단계 (6~12개월)**: 교사 연수 과정, 미국 학교구 대상 영어판(합의 이후 보호 장치 교육 수요 대응)
- **기술 스택**: Next.js, Supabase(Postgres), 익명 설문 집계(최소 집계 단위 적용), LLM은 수업 자료 초안 작성에만 사용

## 5. 수익 모델
- 교사 개인은 무료(수업안 일부). 학교·교육청 연간 라이선스(가설: 학교당 연간 과금, 추정)와 교사 연수 프로그램 판매
- 첫 유료 고객 확보 경로: 디지털 시민교육 예산이 있는 교육청 시범사업, 사립학교 직접 판매

## 6. Go-To-Market
- 교사 커뮤니티(인디스쿨 등)에 무료 수업안을 배포해 교사 사용자를 먼저 확보
- 학부모 대상 "청소년 보호 설정 가이드"를 콘텐츠 마케팅으로 활용하고, 교육청 공모사업에 참여

## 9. 실현 가능성 점수: **3 / 5**
- **기술 난이도**: 낮음. 웹 서비스와 익명 설문 집계는 표준 기술로 충분하다.
- **초기 비용**: 낮음~중간. 현직 교사 자문과 콘텐츠 제작 비용이 주요 지출이다.
- **시장 진입**: 어려움. 학교 조달 절차가 길고, 학생 데이터 규제 대응이 필요하다.
- **수요 신호**: 1건. YouTube 합의 보도는 학교구 단위의 강한 문제의식을 보여 주지만, 근거 항목은 하나뿐이다.
