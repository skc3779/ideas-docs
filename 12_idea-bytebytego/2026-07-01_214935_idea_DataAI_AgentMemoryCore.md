# 2. 제안 범위 및 카테고리

# 3. 해결 문제와 사용자 페르소나
- **해결 문제**:
  - AI 에이전트가 작업을 오래 수행하면 컨텍스트 윈도우가 가득 차 과거에 자신이 내린 중요한 결정이나 코딩 규칙, 사용자 스타일 지침을 망각하는 '장기 기억 유실(Forgetfulness)' 발생.
  - 이를 해결하기 위해 Vector RAG만 사용하면 겉보기 유사도 매칭에 그쳐 인과적 관계나 복잡한 지식 구조를 유지하지 못함.
- **사용자 페르소나**:
  - **오메모(33세, AI 제품 리드 개발자)**: 다단계 사고 판단이 필요한 자사 에이전트 봇을 제작하고 있으나, 대화가 20턴을 넘어가면 봇이 초기의 목적과 중요 제약 사양을 잃어버리고 계속 동일한 코딩 실수를 반복해 속을 썩이는 개발자.

# 4. 핵심 기능/차별점
- **RAG-GraphRAG 듀얼 인덱싱**: 대화와 실행 데이터가 수집되면, 주요 키워드는 Vector 스토어에 넣고 행위 간의 관계성(인과관계, 규칙 등)은 지식 그래프(Knowledge Graph)로 이중 인덱싱하여 다이나믹 가로지르기 지원.
- **TREX 기반 실행 메모리 연계**: 에이전트가 작성한 코드를 단순히 저장만 하는 것이 아니라 실제 실행(Runtime Test) 결과를 에이전트 성능 피드백 루프로 축적, 성패에 따른 '기억 가중치 고도화' 반영.
- **메모리 가비지 컬렉션 (Memory Pruning)**: 단순 중복 대화나 쓸모없는 노이즈를 백그라운드에서 주기적으로 압축 요약하고 필수 핵심 정보만 남겨 토큰 사용 효율 최대화.

# 5. 실행 계획
- **MVP 단계**: 랭체인(LangChain) 또는 어시스턴트 API 기반 자율 에이전트가 단기/장기 메모리를 JSON 및 로컬 지식 그래프 구조(Neo4j)와 연동해 망각 현상을 줄일 수 있는 고속 API SDK 빌드.
- **확장 단계**: 대규모 다중 에이전트 간 메모리 분산 동기화 허브(SaaS) 구축 및 대화형 메모리 디버깅 시각화 관리자 콘솔 제공.
