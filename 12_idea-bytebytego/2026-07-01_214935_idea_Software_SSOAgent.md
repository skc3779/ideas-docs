# 3. 해결 문제와 사용자 페르소나
- **해결 문제**:
  - 엔터프라이즈 고객 수주를 위해서는 반드시 SAML/SSO 싱글사인온 및 SCIM 사용자 프로비저닝(계정 자동 생성/삭제) 기능이 필수적임.
  - 하지만 이를 자사 코드베이스에 연동하는 것은 시니어 아키텍트의 엄청난 리포지토리 정적 리서치 분석과 수십 번의 실패 결제 연동 디버깅 등 평균 3~4주의 기회비용을 허비하게 만듦.
- **사용자 페르소나**:
  - **이창업(34세, 성장기 스타트업 CTO)**: 첫 대형 기업 계약 체결 찬스를 잡았지만, 고객사가 "다음 달 계약 완료 전까지 대기업 전용 Okta SSO 및 SCIM을 필수 조건으로 맞춰오라"고 요구하여, 당장 기능 개발을 수동 진행해야 하는 초조한 스타트업 최고기술책임자.

# 4. 핵심 기능/차별점
- **원격 코드 자동 인플레이스 빌딩(In-place Code Writer)**: 프로젝트 리포지토리를 스캔하여 현재 사용하는 웹 프레임워크(Nest.js, Next.js, FastAPI 등) 및 DB 구조를 자동 디텍팅하고, 그 위에 Auth SDK 연동 코드를 즉시 직접 삽입.
- **로컬 검증 및 타입 체킹**: 코드를 주입한 후 백그라운드에서 실시간 `npm run build` 및 정적 타입 에러를 체크하여, 에러 발생 시 컴파일 피드백 에이전트 루프를 가동해 완전 무오류 자동 리팩토링 수행.
- **Mock 기업 디렉터리 시뮬레이터**: Okta나 Microsoft Entra ID가 없는 개발 환경에서도 테스트할 수 있도록 로컬 가상 SSO/SCIM 피드백 환경 완벽 제공.

# 5. 실행 계획

- **확장 단계**: 멀티 리포지토리 기업 환경 지원 및 사내 독자 로그인 메커니즘을 통합 스캔하여 맞춤 가속화를 돕는 기업 클라우드 콘솔화 확장.
