# 3. 아이디어 제안 (4개)

### [아이디어 1] 기존 코드 분석 및 싱글사인온/SCIM 자동 연동 에이전트 (SSO-Agent)
- **카테고리**: Software (개발 도구 / DevTools)
- **개요**: 레거시 기업 코드를 직접 정적 스캔하여 보안 기업용 복잡한 싱글사인온(SSO)과 SCIM 프로비저닝 코드를 자동으로 코드 내 적재적소에 생성, 빌드, 가속 테스트까지 완료해 주는 기업용 B2B CLI 에이전트입니다.

### [아이디어 2] AI 에이전트 복합 영속성 메모리 관리 오케스트레이터 (AgentMemory-Core)
- **카테고리**: Data & AI (생성형 AI 응용 / LLM App)
- **개요**: RAG, Graph RAG, 에이전트 단기 메모리 기법의 한계를 극복하기 위해 에이전트의 대화 맥락과 실제 과거 작업 수행 실행 이력을 그래프 데이터베이스 및 벡터 검색으로 계층화해 컨텍스트 유실(Forgetfulness)을 예방하는 메모리 미들웨어입니다.

### [아이디어 3] 디지털 패키지 시대 중고 소유권 라이선스 거래 마켓플레이스 (RetroChain)
- **카테고리**: IT Services (마켓플레이스 / Platform)
- **개요**: 실물 패키지 디스크가 소멸하는 디지털 온리 시대를 대비하여, 유저가 온라인 구매한 고전 게임 및 인디 게임의 소유 라이선스를 양도, 중고 거래, 대여할 수 있는 분산형 소유권 인증 기반 마켓플레이스입니다.

### [아이디어 4] 스마트홈 AI 스마트 자동화 및 오토메이션 리뷰 콘텐츠 자동 제작기 (HomeAI-Reviewer)
- **카테고리**: YouTube & Media (AI 자동화 채널 / AI Automation)
- **개요**: 스마트 가전 기기들의 복잡한 오토메이션 시나리오나 스마트 스피커(Google Home 등) 연동 자동화 루틴을 초보자 눈높이에 맞춰 마이크로 비주얼 스틸 애니메이션과 TTS 가이드로 실시간 변환 가공해 유튜브 지식 채널로 송출하는 솔루션입니다.
