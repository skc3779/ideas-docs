# DealTruth-Shorts: 연말 "역대 최저가"를 가격 이력으로 검증하는 AI 자동화 쇼츠 채널

## 1. 제안 범위 및 카테고리
- **영역**: 유튜브 콘텐츠 및 미디어 (YouTube & Media)
- **세부 카테고리**: AI 자동화 채널 / 콘텐츠 분석
- **직전 실행과의 관계**: 신규 (직전 TechInspect-Show는 하드웨어 성능 검증 리뷰였고, 이번에는 할인 가격의 진위를 검증한다)

## 2. 해결 문제와 사용자 페르소나
- **문제 정의**: 블랙프라이데이를 앞두고 Eufy Omni C28이 53% 할인된 379.99달러(정가 대비 420달러 할인)로 소개되는 등 할인 기사가 쏟아진다. 리뷰 매체는 제휴 링크로 수수료를 받는다. GTA VI는 첫날 37.9억 달러 매출과 사전 주문 3,250만 장을 기록해 콘솔·게임 번들 구매 수요도 몰린다. 소비자는 할인율이 정가 기준인지, 최근 실거래가 기준으로도 정말 낮은 가격인지 확인하기 어렵다.
- **타겟 사용자**: 연말 할인 시즌에 가전·게임 기기를 사려는 20~40대 소비자, 해외 직구 이용자
- **페르소나**: 자취하는 30대 직장인. 로봇청소기를 사려고 할인 기사 5개를 비교했지만 "역대 최저가"라는 말을 믿어도 될지 몰라 결제를 미룬다.

## 3. 핵심 기능 및 차별점
| 기능 | 설명 | 기존 대안 대비 차별점 |
|---|---|---|
| 30초 가격 진실 차트 | 제품의 최근 가격 이력을 애니메이션 차트로 보여 주고 "정가 대비 / 90일 최저가 대비" 할인율을 함께 표시 | 할인 기사는 정가 대비 할인율만 강조 |
| 자동 대본·렌더링 | RSS 할인 기사 → 제품명 추출 → 가격 이력 조회 → 대본·차트·자막 자동 생성 → 사람 검수 | 1인이 시즌 중 하루 여러 편을 낼 수 있음 |
| "지금 살까, 기다릴까" 판정 | 가격 이력 기준으로 구매·대기를 간단한 등급으로 제시하고 근거 수치 표시 | 감성 리뷰 대신 데이터 판정 |
| 이벤트 특집 | GTA VI 같은 대형 출시에 맞춰 콘솔·번들 가격 추이 특집 | 시즌 이벤트 검색 수요를 흡수 |

## 4. 실행 계획 (MVP → 확장)
- **MVP 범위 (0~3개월)**: 블랙프라이데이·연말 시즌 쇼츠 하루 2~3편, 가전·게임 기기 카테고리, 공개 가격 이력 데이터 활용, 반자동 렌더링 파이프라인. 만들지 않을 것: 자체 쇼핑몰, 앱, 가격 크롤링 인프라 대규모 구축
- **확장 1단계 (3~6개월)**: 시즌 외 기간에는 "다음 할인 언제?" 예측 콘텐츠, 웹 가격 알림 페이지
- **확장 2단계 (6~12개월)**: 한국 쇼핑몰(쿠팡·11번가 등) 가격 이력으로 확장, 뉴스레터
- **기술 스택**: Python(feedparser), LLM API(제품명 추출·대본), 가격 이력 데이터 API 또는 공개 데이터, Remotion/Manim(차트 렌더링), TTS 또는 진행자 녹음

## 5. 수익 모델
- 제휴 링크 수수료(Amazon 어소시에이트, 국내 쇼핑 파트너스), 쇼츠 광고 수익, 시즌 스폰서
- 첫 유료 수익 경로: 첫 시즌부터 영상 설명란 제휴 링크로 수익이 생긴다. 기사에서 확인되듯 리뷰 매체도 같은 방식으로 수익을 낸다.

## 9. 실현 가능성 점수: **5 / 5**
- **기술 난이도**: 낮음. RSS 수집, LLM 대본, 차트 렌더링은 기존 도구로 충분하다.
- **초기 비용**: 매우 낮음. 1인이 2주 안에 시작할 수 있고, 데이터 API 비용 정도만 든다.
- **시장 진입**: 쉬움. 할인 시즌이 바로 진행 중이고, 제휴 링크 수익 구조가 이미 검증돼 있다.
- **수요 신호**: 2건. 블랙프라이데이 할인 기사와 기록적인 GTA VI 출시가 연말 구매 수요를 보여 준다.
