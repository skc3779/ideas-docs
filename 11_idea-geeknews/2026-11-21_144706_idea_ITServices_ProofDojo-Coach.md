# ProofDojo-Coach: AI는 힌트만 주고 사람이 증명하는 Lean 형식 증명 학습 플랫폼

## 1. 제안 범위 및 카테고리
- **영역**: 서비스 및 플랫폼 (IT Services)
- **세부 카테고리**: 에듀테크
- **직전 실행과의 관계**: 신규

## 2. 해결 문제와 사용자 페르소나
- **문제 정의**: Lean으로 컴파일 가능한 리만 가설 해법 발표 이후, 인간이 직접 탐구하고 발견하려는 의지를 AI에 넘기는 것은 진보가 아니라 항복이라는 반발이 나왔다. 한편 ASI 논의에서는 AI가 대규모 인간 전문가 집단보다 적은 자원으로 성과를 내는 미래가 거론된다. 학습자는 AI가 답을 다 내주는 환경에서 스스로 증명하는 능력을 기를 방법을 찾기 어렵다.
- **타겟 사용자**: 대학 학부 수학·컴퓨터과학 수업 담당 교수와 조교, 수학 올림피아드·영재 교육 기관, 형식 증명을 배우려는 개발자
- **페르소나**: 학부 이산수학 담당 조교. 학생들이 AI로 숙제 증명을 그대로 받아 오는 바람에, 누가 실제로 이해했는지 채점으로 구분하지 못해 고민한다.

## 3. 핵심 기능 및 차별점
| 기능 | 설명 | 기존 대안 대비 차별점 |
|---|---|---|
| 힌트 사다리 | AI 코치가 질문 → 방향 제시 → 다음 전술 순으로 단계별 힌트만 주고, 과제별로 힌트 상한을 둠 | 일반 AI 챗봇은 바로 완성된 답을 줌 |
| 학습자 기여율 | 최종 증명 중 학습자가 직접 쓴 전술 비율을 표시 | 결과만 채점하는 대신 과정을 평가 |
| Lean 자동 채점 | 브라우저에서 Lean 4를 실행해 즉시 통과/실패 확인 | 기존 Lean 튜토리얼은 진도 관리와 반 운영 기능이 약함 (추정) |
| 반 운영 대시보드 | 교수자용 과제 배포, 힌트 사용 통계, 막힌 지점 분석 | LMS와 형식 증명 도구가 분리돼 있던 문제 해결 |

## 4. 실행 계획 (MVP → 확장)
- **MVP 범위 (0~3개월)**: 입문 과제 30개(명제 논리·집합·귀납법), 힌트 사다리, 브라우저 Lean 실행, 반 1개 단위 대시보드. 만들지 않을 것: 자체 증명 모델, 모바일 앱, 고급 해석학 과정
- **확장 1단계 (3~6개월)**: 교수자 과제 저작 도구, LMS(Canvas·Moodle) 연동, 한국어·영어 과정
- **확장 2단계 (6~12개월)**: 올림피아드 트랙, 학습자 포트폴리오 인증서, 기업 개발자용 "형식 검증 입문" 과정
- **기술 스택**: Lean 4 + mathlib, lean4web 계열 브라우저 실행 환경, LLM API(힌트 생성, 정답 노출 차단 프롬프트), Next.js, Postgres

## 5. 수익 모델
- 개인 학습자는 무료(힌트 사용량 제한), 교육기관은 반·학기 단위 라이선스(가설: 학생당 학기 과금, 추정)
- 첫 유료 고객 확보 경로: AI 표절 문제로 고민하는 학부 수학 수업 2~3곳에 학기 무료 파일럿을 제공한 뒤 학과 단위로 전환

## 9. 실현 가능성 점수: **3 / 5**
- **기술 난이도**: 낮음~중간. Lean 4 브라우저 실행과 LLM 힌트는 기존 오픈소스·API로 구현할 수 있다.
- **초기 비용**: 낮음. 다만 양질의 과제 콘텐츠를 만드는 데 전문 인력이 필요하다.
- **시장 진입**: 보통. 형식 증명 교육 시장은 좁고 교육기관 영업 주기가 길다.
- **수요 신호**: 사실상 1건. 근거 기사 2건이 같은 리만 가설 사건을 다루고, ASI 기사는 간접 근거다.
