# 3. 해결 문제와 사용자 페르소나
- **해결 문제**:
  - '지식 탐구형 테크 유튜브 채널'은 탄탄한 조회수와 고품질 팬덤을 모으기에 아주 좋으나, 정교한 대본 고증, 역사적 아카이브 인물 사진 탐색, 나레이션 및 자막 교차 편집 작업에 엄청난 제작 노력과 일주 이상의 시간이 요구됨.
  - 대형 AI 비디오 자동 생성 도구들은 단순한 스톡 영상 나열에 그쳐, 테크 역사 특유의 '전문성'과 '흥미진진한 고증 서사'를 살리지 못해 지루함.
- **사용자 페르소나**:
  - **오피디(31세, 1인 지식 유튜브 크리에이터)**: 컴퓨터 과학 및 테크 기업 흥망성쇠 채널을 키우고 싶어 하지만, 퇴근 후 대본 리서치와 사진 누끼 따기, 나레이션 녹음 작업의 장벽에 부딪혀 결국 지속적인 연재를 포기하기 일쑤인 지식 직장인.

# 4. 핵심 기능/차별점
- **위키/아카이브 지식 기반 자동 스토리텔링**: 인물이나 기술명(예: 빈트 서프, 리스크 프로세서, 인터넷의 탄생)만 입력하면, LLM이 전문 위키 백과와 아카이브 데이터에서 뼈대 서사를 추출해 흥미진진한 다큐 시나리오로 대본화.
- **아카이브 소스 검색 및 스틸컷 생성**: 검색 API를 연동하여 실제 역사적 실제 인물 사진을 매칭하고, 저작권 이슈가 있는 구간은 최신 미드저니/DALL-E 프롬프트로 극사실주의 역사 삽화(Illustration)를 완전 자동 생성 삽입.
- **버추얼 역사 해설가(Avatar) 프레젠테이션**: AI 아바타가 3D 스튜디오 배경에서 직접 칠판이나 슬라이드를 넘기며 설명해 주는 프리미엄 해설 스타일의 비디오 합성 지원.
