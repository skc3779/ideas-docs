# 1. 아이디어명
- **코드 그래프 분석 기반 LLM 토큰 세이버 MCP 서버 (CodeGraph-MCP)**

# 2. 제안 범위 및 카테고리
- **제안 범위**: Software
- **카테고리**: 개발 도구 (DevTools)

# 3. 해결 문제와 사용자 페르소나
- **해결 문제**:
  - Claude Code 나 Cline 같은 강력한 터미널 기반 AI 개발 어시스턴트가 프로젝트 컨텍스트를 파악하려다 보니, 코드 파일 전체를 읽어 들여 막대한 API 비용과 속도 저하, 토큰 한계 도달 문제를 야기함.
  - 전체 파일 중 특정 함수와 의존성만 읽으면 되는데도 고효율 컴파일 지식(AST)이 적용되지 않아 단순 무식한 소스 수집만 실행되고 있는 구조적 비효율.
- **사용자 페르소나**:
  - **강토큰(28세, 백엔드 엔지니어)**: 매일 Claude Code와 짝프로그래밍을 진행하지만, 매번 몇 번 질문하지도 않고 "API Limit Reached" 및 일일 예산 한도(월 $100+)를 날려버려 업무 흐름이 자주 끊기는 헤비 AI 어시스턴트 사용자.

# 4. 핵심 기능/차별점
- **AST 기반 선택적 코드 주입**: 파일 전체를 전송하는 대신, 컴파일러(AST 파서)를 통해 질문과 관련된 정확한 의존성 함수, 클래스 선언부, 리턴 타입 정보만 추출해 LLM 컨텍스트에 포함.
- **MCP 표준 완전 준수**: Claude Desktop, Cursor, VS Code, Claude Code와 직접 연동되는 표준 MCP 서버 규격 지원.
- **토큰 소모 대시보드 및 지표**: 질문당 절약된 토큰 비중(%) 및 월간 API 가치(USD)를 로컬 대시보드로 실시간 확인 가능.

# 5. 실행 계획
- **MVP 단계**: TypeScript 컴파일러와 연계하여 TS/JS 파일 내 함수 단위 호출 그래프(Call Graph)만 로컬에서 파싱해 Claude에 전송하는 단일 언어 타겟 MCP 서비스 개발.
- **확장 단계**: Python, Go, Java 등 엔터프라이즈 주력 언어 지원 확장 및 클라우드 동기화 중앙 공유 스키마 저장소 도입.

# 6. 수익 모델
- **오픈소스 코어 + 상용 부가 모델 (Open-Core)**: 기본 MCP 기능은 로컬 오픈소스로 무료 공개하여 대형 커뮤니티 트래픽을 선점.
- **엔터프라이즈 플랜**: 코드 보안 감사, 대규모 레포 통합용 멀티 클라우드 인덱싱 어댑터 월 구독형($19 / 개발자당).
