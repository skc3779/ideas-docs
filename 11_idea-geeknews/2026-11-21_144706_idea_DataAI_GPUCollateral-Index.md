# GPUCollateral-Index: GPU 담보 대출을 위한 AI 칩 잔존가치·담보 리스크 지표

## 1. 제안 범위 및 카테고리
- **영역**: 데이터 및 인공지능 (Data & AI)
- **세부 카테고리**: Vertical AI / DataOps
- **직전 실행과의 관계**: 신규

## 2. 해결 문제와 사용자 페르소나
- **문제 정의**: 데이터센터 생태계는 부채 금융에 의존하고, 대출은 보통 칩을 담보로 잡는다. 그런데 AI 투자 열풍의 지속 가능성 우려가 커지고, Nvidia 주가가 약 14% 급락했으며, AI 데이터센터 건설 둔화 우려도 나온다. 이런 상황에서 담보로 잡은 칩이 몇 년 뒤 얼마의 가치를 가질지 추정할 공개 지표가 부족하다. 우주 데이터센터처럼 담보 회수 자체가 어려운 구조도 논의되고 있다.
- **타겟 사용자**: GPU 담보 대출을 검토하는 사모 크레딧 펀드·은행 인프라 금융팀, GPU 클라우드 사업자의 재무팀, 중고 GPU 브로커
- **페르소나**: 인프라 크레딧 펀드의 애널리스트. 신생 GPU 클라우드의 대출 심사 메모를 쓰면서 GPU 세대별 감가 가정을 엑셀로 손수 만들고, 근거를 묻는 투자위원회 질문에 답하지 못한다.

## 3. 핵심 기능 및 차별점
| 기능 | 설명 | 기존 대안 대비 차별점 |
|---|---|---|
| 잔존가치 곡선 | GPU 모델별 임대 단가·중고 호가·신제품 출시 일정으로 월별 잔존가치 추정 | 감정평가 보고서는 건별 비용이 크고 갱신이 느림 (추정) |
| 스트레스 시나리오 | 임대 단가 하락, 세대 교체 가속, 데이터센터 건설 둔화 시 담보 커버리지(LTV) 변화 계산 | 엑셀 수작업 대신 같은 가정을 재현 가능하게 공유 |
| 회수 난이도 점수 | 설치 위치(지상/해외/궤도), 냉각·전력 의존도에 따른 회수 가능성 등급 | 우주 데이터센터 같은 새 구조의 담보 리스크를 별도 항목으로 평가 |
| 뉴스 신호 피드 | 관련 기사·공시를 LLM이 요약해 리스크 이벤트로 태깅 | 시장 소식과 담보 모델을 한 화면에서 연결 |

## 4. 실행 계획 (MVP → 확장)
- **MVP 범위 (0~3개월)**: 주요 데이터센터 GPU 5~8종의 공개 임대 단가 수집기, 단순 감가 모델, 주간 리포트(PDF). 만들지 않을 것: 투자 추천, 개별 기업 신용등급, 실시간 거래 기능
- **확장 1단계 (3~6개월)**: 브로커·클라우드 사업자와 데이터 제휴(익명 거래가 제공 대가로 지표 무료 이용), API 제공
- **확장 2단계 (6~12개월)**: 포트폴리오 단위 스트레스 테스트, 대출 계약서 조항(담보 교체·회수) 비교 분석
- **기술 스택**: Python 크롤러, DuckDB/Postgres, 생존분석 기반 감가 모델, LLM 뉴스 태깅, Streamlit 또는 Next.js 대시보드

## 5. 수익 모델
- 기관 구독(가설: 좌석당 연간 계약, 추정)과 건별 담보 평가 리포트 판매
- 첫 유료 고객 확보 경로: GPU 클라우드에 대출을 실행한 중소형 크레딧 펀드에 무료 샘플 리포트를 제공한 뒤 유료로 전환

## 6. Go-To-Market
- 매주 "GPU 담보 지수" 뉴스레터를 무료로 내서 금융·인프라 업계 독자를 모은다
- 데이터센터 금융 컨퍼런스와 링크드인 장문 분석글로 인지도를 쌓고, 브로커와 데이터 교환 제휴를 맺는다

| 지표가 투자 자문으로 해석될 위험 | 규제 이슈 | 리스크 분석 데이터로만 제공하고 매수·매도 의견은 내지 않음 |

## 9. 실현 가능성 점수: **3 / 5**
- **기술 난이도**: 중간. 수집과 감가 모델은 표준 기법이지만, 품질 좋은 거래 데이터 확보가 핵심 기술 과제다.
- **초기 비용**: 중간. MVP는 작게 시작할 수 있지만 데이터 구매·제휴 비용이 생길 수 있다.
- **시장 진입**: 어려움. 금융 기관 고객은 신생 데이터 업체를 쉽게 신뢰하지 않는다. 핵심 가정(데이터 접근)이 검증되지 않았다.
- **수요 신호**: 2건. 칩 담보 금융 구조의 리스크 제기와 AI 투자 조정·데이터센터 둔화 우려가 있다.
