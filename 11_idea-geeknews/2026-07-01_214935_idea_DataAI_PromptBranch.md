# 4. 핵심 기능/차별점
- **대화 흐름 트리 시각화(Tree UI)**: 대화 도중 "여기서 다른 가정을 세워보자" 하고 새 채팅 분기를 만들면 마인드맵 노드 형태로 사이드 패널에 분기가 자동 생성되어 한눈에 탐색.
- **다중 모델 병렬 테스팅**: 하나의 프롬프트 입력을 트리 분기 지점에서 Fable, Mythos, GPT 등 다양한 모델에 동시에 분사하여 결과를 가로 비교(Side-by-side) 분석.
- **분기 템플릿 코드 Export**: 완성된 대화 시나리오 트리를 클릭하면 프로그래밍 에이전트(LangChain, LlamaIndex, Python SDK 등)의 시나리오 분기 코드로 즉시 변환 출력.
