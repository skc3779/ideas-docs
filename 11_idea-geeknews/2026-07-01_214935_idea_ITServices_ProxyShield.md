# 4. 핵심 기능/차별점
- **실시간 ISP IP 행위 분류**: 요청 IP의 패킷 전송 특성(TTL, TCP 핑 지연, 이력 분석)을 통해 데이터 센터에서 출발한 주거용 프록시 우회망 노드인지를 실시간 판별.
- **동적 평판 점수 API (IP Reputation)**: 요청 발생 시 0-100점의 위험도 점수를 0.01초 내 반환하여, 핀테크 간편 결제 및 선착순 예약 구매 절차에서 고위험 IP 트래픽을 자동 차단 또는 2차 인증(MFA) 강제 처리.
- **위협 프록시 허니팟망**: 지속해서 주거용 프록시 대여 시장의 타겟 대역을 수집하고 업데이트하는 자동 블랙리스트 동기화 허니팟 구축.

# 5. 실행 계획

- **확장 단계**: 대량의 IP 평판 분석 빅데이터 파이프라인(Data Pipeline)을 확대하고 대기업 및 금융권 결제 사기 탐지(FDS) 솔루션에 보안 모듈로 결합 납품.
